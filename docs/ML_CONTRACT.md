## 2. Statistical Window Features Contract (`TemporalWindowFeatures`)

| Feature Name | Statistical Formula / Basis | Role in Forecasting |
|---|---|---|
| `flow_volume` | Total flows in sliding time $\Delta t$ | Baseline volume shifts |
| `packet_volume` | Sum of packet counts | Volumetric attack detection |
| `byte_volume` | Sum of byte counts | Data exfiltration indicator |
| `unique_source_ips` | Cardinality of source IP set | Botnet / multi-source indicator |
| `unique_destination_ports` | Cardinality of destination port set | Port scanning vs focused attack |
| `syn_ack_ratio` | $\frac{\text{Count}(\text{SYN})}{\text{Total Flows}}$ | Half-open SYN flood indicator |
| `rst_ratio` | $\frac{\text{Count}(\text{RST})}{\text{Total Flows}}$ | Connection teardown anomaly |
| `entropy_dest_ports` | $-\sum p_i \log_2(p_i)$ over destination ports | Port distribution dispersion |
| `entropy_source_ips` | $-\sum p_j \log_2(p_j)$ over source IPs | Source dispersion / distribution |
